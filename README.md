# DSSSB TGT Computer Science — PYQ Trainer

A personal, mobile-friendly practice app for DSSSB TGT (Computer Science) previous-year questions: topic-wise theory notes, MCQs with answers and explanations, daily streaks, XP, badges and a progress dashboard. Progress is stored only in your own browser (localStorage).

Live site: https://sahilkumar1122.github.io/dsssb-tgt-cs-pyq-trainer/

Question text is compiled from publicly conducted exam papers as presented on the KnowledgeGate course platform. This is a personal, non-commercial study aid — not promoted or sold.
